## C-SIG-01 | Discrete LFM and matched filter
N=128, fs=1e6 Hz, L=16 samples, pulse length T=16us, B=250kHz; midpoint sample t_j=(j+0.5)/fs for j=0..15 and chirp rate mu=B/T. Complex baseband pulse s[j]=exp(i*2*pi*(-B*t_j/2+mu*t_j*t_j/2)). Its continuous instantaneous frequency sweeps -125 to +125kHz; sampled first/last instantaneous frequencies are -117187.5 and +117187.5Hz. Rectangular duration 16 samples and s=0 outside support. Reference chirp unit modulus, deterministic phase at t=0=0.
Input echo for integer delay k and slow pulse m: a*s[n-k]*exp(i*2*pi*fd*m*PRI+i*phi), PRI=1ms, fd=2*v/lambda with positive v approaching. Each echo lies k..k+15; full echo contained iff 0<=k<=112. Physical range per delay sample uses exact c=299792458m/s, deltaR=149.896229m; 150m is rounding only. Grid suite target delays k=20,40,60 represent close approximations to 3,6,9km; exact nominal distances use a fractional-delay separately defined suite, not silently rounded truth.
h[j]=conj(s[15-j]) for j=0..15. Linear convolution z=x*h has output index q=0..142. Delay-aligned MF p[k]=z[k+15], with zeros outside input support. Noiseless isolated full echo has peak index exactly k after delay compensation, and theoretical peak magnitude=16*|a|. Define MF range search k=0..112; edge k=0,112 examined separately. Do not mistake full-echo support for CFAR CUT-valid range. Peak equality cases are explicit errors in clean single-target grid tests, not silently resolved.
Numerical taps and fixed-point bit growth follow S04; measured range sidelobes and two-target separability are S03 responsibilities. 600m nominal c/(2B) resolution is theory, not measured outcome.

## C-DAT-01 | Binary IQ, noise, SCR and reproducibility
IQ wire bytes: pulse-major m=0..32 then range n=0..127; each sample I then Q, little-endian two's-complement int16 each, total 33*128*4=16896B. Candidate signed Q1.15 binary conversion for normalized signal: integer=clip(round_to_nearest_ties_even(x*32768),-32768,32767). Exact non-clipping source normalization to be tracked; any saturated samples reported and clean vectors require zero saturations. Raw byte vector and metadata have separate SHA-256 hashes.
Save fixed PCG64 algorithm/version with NumPy version, 128-bit seed decimal representation and independent CPI/scenario substream seeds; generator source hash, environment lock, sample ordering, exact parameter manifest, quantizer mode, clipping count and raw-vector hash. Bit-identical replay required for pinned environment and frozen vector artifact; not claimed across unrelated library versions.
For isolated target i, average P_echo_i=sum_j|a_i*s[j]|²/16 over active echo only; w~CN(0,sigma²), E|w|²=sigma², real/imag each variance sigma²/2. SNR_i=10log10(P_echo_i/sigma²) measured at ideal complex input before summing noise and before quantization. At 0,10,20dB choose sigma² accordingly; finite record measured SNR and Monte Carlo confidence reported separately without claiming exact realized noise power each CPI.
SCR_i=10log10(P_echo_i/P_clutter_i); P_clutter_i is average |c[m,n]|² on the active echo support n=k_i..k_i+15, m=0..32. For multi-target cases report each mask; the +10/-10dB scenario uses homogeneous clutter power across all defined masks; heterogeneous clutter reports distinct SCRs. No-clutter separate. Define statistical sample tolerance in S03 generator test before execution. Input echoes fractional delay off grid belong to separate explicit suite.

## C-DOP-01 | MTI, FFT, deterministic ties, and test eligibility
MTI first-difference y[m,k]=p[m+1,k]-p[m,k], m=0..31. Signed unshifted DFT uses b=0..15 -> b_s=b, b=16..31 -> b_s=b-32; bin 16 is negative Nyquist. Approaching is positive. Historical accepted nominal speed-bin spacing 0.46875 m/s uses c_ref=3e8 m/s; velocity half-bin limit 0.234375 m/s. Distinguish exact-c reporting from this explicitly fixed nominal Doppler label convention.

NORMATIVE DETERMINISTIC OUTPUT RULE (all input states, not limited to performance-qualified trials): compute 32 power values in final fixed-point representation per range cell; choose bin with highest numerical power. If several bins have exactly equal maximum quantized power, choose the bin having the smallest signed b_s; if needed, smallest unshifted b as secondary tie-break. Return selected bin and deterministic status; on all-zero bins (including MTI-stationary target), emit NO_VALID_PEAK status rather than invent a velocity, while preserving a deterministic default index sentinel in the output schema to be frozen in S05. For nonzero exact ties, report PEAK_TIE flag. FPGA vs bit-true reference must agree exactly for normal, tie, zero and overflow cases. A tie does NOT permit nondeterministic RTL output.

SEPARATE HALF-BIN ELIGIBILITY (not a general failure waiver): an isolated dominant test target is eligible for half-bin velocity-error assessment iff its true unambiguous velocity is within the selected folded interval, input target is not stationary/DC-nulled, output power peak is strictly >0 and the computed maximum has exactly one bin (no exact ties), and the peak power exceeds both adjacent circular bins; label the result ELIGIBLE. Without these conditions label NOT_ELIGIBLE with reason and retain it in test denominators and separate summary. Each planned on-bin and off-bin test group must report attempted, eligible and ineligible counts, and no ineligible test may be silently dropped. In the qualifying tests, nearest-bin error <=0.234375 m/s; peak border/bin-tie tests must pass deterministic bit-true output and status rules but are not adjudicated by the half-bin bound. S02 has no approved minimum eligibility fraction across stochastic tests; it cannot claim success for a test set containing no eligible trials. Any new requirement for minimum fraction needs engineer-approved protocol revision before testing.

LEAKAGE AND TRUTH ASSOCIATION: rectangular 32-bin FFT baseline. Leakage power ratio in dB: 10log10(sum outside peak/max(peak,eps)) for a single target, with eps pre-frozen in the numerical reference. Truth matching is host-side performance scoring, distinct from FPGA grouping. Form feasible matches using assignment gate R_GATE=2*range_sample_spacing and V_GATE=1*velocity_bin_spacing (in consistent nominal c=3e8 reporting convention). Build cost C=(dR/R_GATE)^2+(dv/V_GATE)^2 for pairs within both gates. Optimize (1) cardinality maximum (2) total cost minimum (3) lexicographically smallest matching pairs (truth ID, detection ID). No truth or detection is assigned twice. Assignment gate determines which detections count as candidate matches ONLY; it must never replace or weaken the separate estimator acceptance threshold. Full details are independent structured fields in v0.7 matrix.

## C-CFAR-01 | 2D CA-CFAR and preregistered rare-event coverage qualification
CFAR geometry UNCHANGED from approved v0.6: full 7x7 neighborhood, central 3x3 excluded, 40 training cells; range CUT k=3..109, unshifted Doppler bin CUT b=3..28, 2782 valid CUT/CPI. Input is linear RD power. Decision P_CUT > alpha*(sum of 40 training powers/40). Initial IID-exponential alpha=40*(0.001^(-1/40)-1) is only a design starting point because MF/MTI/FFT induce dependencies. Calibration corpus must be disjoint from validation and its algorithm/predeclared stopping must be frozen.

Pfa VALIDATION PLAN (unchanged thresholds): For the independently seeded noise-only, target-free and clutter-free 4096-CPI validation set, count F_i alarms over 2782 CUTs per CPI. Point estimate p_hat=sum_i F_i/(4096*2782). Upper one-sided nominal 95% CI U is the 9500th sorted value from 10000 bootstrap resamples, each resampling all 4096 whole CPI IDs with replacement, fixed bootstrap seed 20261109. This preserves arbitrary within-CPI dependence. Number of CPIs fixed at 4096, no early stops or after-result extension. If qualification passes, Pfa PASS iff U<=0.0015.

COVERAGE METHOD QUALIFICATION, TO BE EXECUTED BEFORE ANY Pfa ACCEPTANCE TEST, NOT EXECUTED AT S02:
Define nominal coverage at generating probability p as Pr_p[U >= p], with equality counted covered. This is distinct from the Pfa acceptance bound 0.0015. For each independent outer study repetition, generate exactly 4096 independent CPI alarm-count vectors under a specified model, compute U with the **identical** 10000-whole-CPI bootstrap method and assess indicator 1[U>=p]. Freeze all models and parameters before running the study; each study condition uses 1000 independent outer repetitions, with independent RNG streams and saved model and code hashes. The inner bootstrap uses deterministic substream keyed by (model_id, p, correlation_parameter, repetition_id) and fixed master seed 20261109. The model data are binary alarm indicators on 107x26 eligible CUT grid per CPI, independently regenerated across CPIs.

MODEL A, IID NULL: for each CUT Bernoulli(p), independent both within and across CPI.
MODEL B, BETA-BINOMIAL EXCHANGEABLE WITHIN CPI: for rho>0, sample q_i~Beta(a,b), a=p*(1/rho-1), b=(1-p)*(1/rho-1), then conditional on q_i sample 2782 Bernoulli(q_i) cells; CPI independent. With rho=0 revert IID. Use rho in {0.01,0.05}.
MODEL C, SPATIALLY CORRELATED GAUSSIAN COPULA: for each CPI draw a zero-mean unit-variance 107x26 Gaussian field with covariance Cov(Z[r,b],Z[r',b'])=(rho_r^abs(r-r'))*(rho_d^abs(b-b')); alarm indicator 1[Z>Phi^-1(1-p)]. CPI fields independent. Use (rho_r,rho_d) in {(0.4,0.25),(0.8,0.6)}. p is an *exact marginal false-alarm probability by construction*; the dependent field is an explicit surrogate stress model, not falsely presented as a validated representation of CA-CFAR outputs.
For each of these FIVE dependency models (IID, beta rho 0.01, beta rho 0.05, Gaussian weak, Gaussian strong), run each p in {0.0005,0.001,0.0015}; 15 predefined conditions, 1000 outer repetitions per condition, each performing the original 4096-CPI/10000-bootstrap CI procedure. No condition can be dropped after observing results. This is a computationally heavy S03 statistical method-qualification task, not a S02 execution claim.

UNCERTAINTY OF COVERAGE ITSELF: For each condition estimate coverage C_hat=covered/1000 and its **one-sided lower 95% Wilson score bound** L95(C) using z=1.6448536269514722 and n=1000:
L95=(C_hat+z^2/(2n)-z*sqrt(C_hat*(1-C_hat)/n+z^2/(4*n^2)))/(1+z^2/n).
QUALIFICATION PASS iff L95(C)>=0.95 for **every** one of the 15 predeclared conditions. With n=1000 this requires at least 962 covered repetitions in every condition (exact integer check). The Wilson lower bound accounts for Monte Carlo uncertainty in estimated coverage. This is 15 separate one-sided 95% condition-level tests; it does not establish a simultaneous 95% confidence claim across all 15 conditions. Because every condition must pass, no multiplicity-corrected global statistical confidence is asserted. The study may fail to qualify the basic percentile-bootstrap method; this is acceptable engineering evidence of inadequacy, not grounds for quietly changing the criterion.

Outcomes: qualification PASS => permit separate real CA-CFAR noise-only baseline Pfa validation using same CI method and fixed 4096 CPIs. QUALIFICATION FAIL (or incomplete/invalid study) => Pfa verification status INCONCLUSIVE/BLOCKED, do not claim acceptance even if observed upper bound seems small; any replacement CI method needs engineer-approved protocol revision BEFORE running new acceptance data. Validation never used to tune coverage or choose model/threshold. Keep full counts, seeds, bootstrap/PRNG versions, pseudocode or source hash, condition results and L95 audit.
Pd>=0.9 at 20dB remains a design target with S03 feasibility gate; 0/10dB only report Pd. Clutter-dependent Pfa is separately tested, without extrapolation from this Gaussian noise-only contract.

## C-UART-01 | FPGA UART transport and debug readback
Onboard CP2102GM, initial UART 8N1 at 115200 baud (must be confirmed on board). Byte frame: four-byte SOF A5 5A C3 3C; uint8 version=1; uint8 type; uint8 flags; little-endian uint32 sequence; little-endian uint16 payload length 0..512; payload; little-endian uint32 CRC-32. CRC over bytes from version through end of payload, excluding SOF and CRC itself. CRC-32/ISO-HDLC reflected polynomial 0xEDB88320, initial register FFFFFFFF, final XOR FFFFFFFF; standard check ASCII 123456789 -> CBF43926. Maximum frame size 529 bytes. Parser accepts frame only after version/type/length/expected sequence and CRC validation, and resynchronizes by byte scanning after malformed length, timeout or CRC error. SOF appearing in payload alone is not sufficient for acceptance.
Define packet TYPE command, IQ_UPLOAD, STAGE_REQUEST, STAGE_DATA, RESULT, ACK, NACK, STATUS; distinct values fixed by ICD no later than S05. IQ_UPLOAD carries uint32 CPI ID and uint32 byte offset preceding chunk data. Reassembly must cover all 16896 bytes with no missing or overlapping byte ranges; full CPI uploaded and acknowledged before run command. A readback or full-CPI digest must be used to verify host bytes; SHA-256 on FPGA is not required if equivalent byte-accurate host readback exists.
Stop-and-wait ARQ: monotonic sequence per link direction; ACK exact sequence, duplicate acknowledged idempotently without reapplying payload, out-of-order NACK with expected sequence, up to 3 retransmissions after initial send, timeout nominal 2s per frame at configured 115200 baud, abort CPI with explicit status on exhaustion; no invisible completion. Fault test matrix corruption, truncation, CRC changes, duplicate, missing, reorder, timeout and recovery. For all *injected test faults*, require either appropriate retry/recovery or unambiguous failure, never a falsely successful CPI. CRC detects many but not mathematically all error patterns.
Full intermediate output for each of seven FPGA functions accessible by stage request and segmented STAGE_DATA with CPI/offset/type/schema; deterministic reruns allowed without simultaneous buffer retention. Binary readback compared bytewise with corresponding bit-true reference under identical initial conditions. Timing metrics distinguish link transfer time and FPGA-only cycle measurement.

## C-CFAR-02 | Statistical feasibility review and proposed efficient CPI-cluster method

### Existing v0.7 nested percentile-bootstrap method (retained as previous version, NOT run)
There are 5 dependency models x 3 p values x 1000 independent outer studies = 15000 studies. Each study has 4096 independent CPIs and 10000 cluster bootstrap repetitions of 4096 resampled CPI indices. That is 150 million inner bootstrap estimates and 614,400,000,000 CPI-index draws, plus 15000 x 4096=61,440,000 modeled CPIs and, if all 2782 CUT events are generated, 170,926,080,000 CUT indicators. Computational complexity for index drawing is Theta(15000*10000*4096); if all binary CUTs materialized, additional Theta(15000*4096*2782). For uint32 indices, cumulative raw write volume 2.4576 terabytes; per-study 10000x4096 uint32 index matrix ~156.25 MiB. Streaming prevents holding cumulative arrays in RAM, not the time cost. The physical laptop inspection recorded i5-1235U (10 physical core design, 12 logical CPUs), 15GiB RAM, 9.2GiB available at inspection, NumPy 2.3.5 and SciPy 1.16.3. CPU/wall-time not benchmarked; feasibility assertion only that streaming memory fits, not that cost is operationally justified.

### Candidate v0.8 cheaper method; NOT automatically approved, not tested
Define independent observational cluster i as an entire noise-only CPI with M=2782 valid CUTs, alarm count F_i in [0,M], and X_i=F_i/M in [0,1]. Between CPI independence is required; arbitrary dependence within each CPI is allowed for computing a cluster-sample standard error. With G=4096 fixed independent CPIs, p_hat=mean(X_i), s^2=sum_i(X_i-p_hat)^2/(G-1), U_t=min(1,max(0,p_hat+t_{0.95,G-1}*s/sqrt(G))). Here t quantile is one-sided Student t with G-1=4095 df. Report F_i and X_i, skewness, number K_positive of CPI with >=1 alarm, total alarms A, and sample variance.

Two guardrails: if K_positive<100 OR A<100 OR s=0 OR invalid CPI/test setup, label INCONCLUSIVE, never PASS, regardless of U_t. These are preregistered conservative data-sufficiency checks rather than a claim that 100 events mathematically guarantees a good normal approximation. No fixed run-time stopping and no after-the-fact extra CPI allowed. On qualified method + data-valid: PASS baseline Pfa iff U_t<=1.5e-3, otherwise FAIL. Nominal 95% t coverage is asymptotic and may fail for rare skewed count distributions: a preregistered independent coverage study is therefore mandatory before using it for a Pfa PASS/FAIL verdict. If coverage qualification fails, all corresponding Pfa decisions are BLOCKED/INCONCLUSIVE; a replacement protocol needs explicit engineer acceptance before creating new validation data.

### Reduced-count-only coverage study (fixed before execution)
Maintain p in {0.0005,0.001,0.0015}, M=2782, G=4096, 1000 independent outer repetitions/condition and fixed 15 conditions. Use five count-generating models, *without generating all 2D CUT cells*, and independent outer-study/CPI PRNG substreams:
Model A: F_i~Binomial(M,p), IID CUTs.
Model B1: q_i~Beta(a,b), a=p*(1/rho-1), b=(1-p)*(1/rho-1), then F_i|q_i~Binomial(M,q_i), with rho=0.001.
Model B2: same, rho=0.01.
Model B3: same, rho=0.03.
Model B4: same, rho=0.05.
All CPIs i and outer studies independently generated, within-CPI count variance increasing with rho. These exchangeable correlated-count surrogate models *do not reproduce spatial anisotropy, CA-CFAR threshold feedback, exact FPGA outputs or actual MTI/MF/FFT dependence*. They test a specified overdispersion envelope only. Separate spatially realistic CA-CFAR reference scenarios and dependency diagnostics in S03 are required; failure of those diagnostics blocks extrapolation of this qualification to operational clutter.

For each outer study compute U_t on the 4096 CPI counts, record coverage indicator I=1[U_t>=true p], and record inconclusive indicator from above guardrails; for coverage conservatively set U=1 if INCONCLUSIVE (coverage indicator then 1), BUT count such studies in an independent inconclusive-rate test. Let C_hat=sum I/1000, Q_hat=sum inconclusive/1000. Compute one-sided 95% Wilson LOWER for C_hat and one-sided 95% Wilson UPPER for Q_hat with z=1.6448536269514722. Qualification PASS only if, for ALL 15 predeclared conditions, lower_Wilson_95(C_hat)>=0.95 AND upper_Wilson_95(Q_hat)<=0.05. These are conditionwise confidence assertions; no 95% simultaneous family coverage claim. All runs fixed in advance, no early stopping or posthoc condition removal. A failed condition implies qualification failure with evidence and a new engineer-approved protocol needed before attempting main Pfa acceptance.

Computational cost after replacing bootstrap inner loop: 15000*4096=61,440,000 CPI-count draws plus constant-time sample mean/variance per outer study; O(61.44 million) (up to algorithmic random sampler cost), memory O(4096) sample counts (~8 KiB uint16, plus working arrays), as opposed to ~614.4 billion CPI index draws. Storage of summary condition outcomes is tiny; do not retain all outer trial arrays unless required by audit. The new method is cheaper, NOT inherently more statistically valid than cluster bootstrap; its intended validity is conditional on measured coverage qualification and source-independence assumptions. No actual statistical simulation was run in S02.
