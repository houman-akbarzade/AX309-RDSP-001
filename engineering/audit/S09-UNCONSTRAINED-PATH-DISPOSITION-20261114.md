# S09 — disposition of paths reported as unconstrained

Date: 2026-11-14. The source for this classification is a second TRCE invocation on the same routed NCD and PCF: `trce -v 1 -u 5000 -s 2`. Full report generated at `/tmp/S09-all-unconstrained-20261114.twr`; its reproducible source command and the archived 20-path sample are retained in the S09 audit. This is report inspection, not a changed UCF or new bitstream.

- All 4376 paths in the unconstrained path-analysis section have `Source: clk50 (PAD)`, with 4131 FF clock endpoints, 236 RAM clock endpoints, and 9 DSP clock endpoints. These are clock-distribution paths via BUFG, not register-to-register functional data paths. The 20-path archived sample shows the physical clock-pin routing. Their count is not evidence that 4376 data paths escaped the 20 ns period constraint.
- The 4 OFFSET IN paths start at `reset_n` or `uart_rxd`. The RTL has asynchronous assertion and three-cycle synchronous release of reset (`radar_ip_ax309_top.v`), and a two-register receive synchronizer before UART sampling (`uart_rx_8n1.v`). The external transitions have no guaranteed phase to the 50 MHz oscillator. No synchronous external OFFSET IN number has been supplied, and imposing an arbitrary number would not certify metastability or reset-release behavior.
- The 1 OFFSET OUT path terminates at `uart_txd`. TRCE reports maximum clock-to-pad 9.216 ns; the UART receiver consumes the asynchronous serial bit after framing/oversampling, so a board-level synchronous output OFFSET is not a meaningful acceptance criterion absent an external synchronous interface requirement. The bit period is generated from 50 MHz/115200 and UART integrity is tested at S11.
- The 20 ns synchronous constraint covers 784082425 paths with worst setup slack +0.598 ns, worst hold slack +0.306 ns, zero setup/hold failures; PAR routing is complete.

**Recommendation:** record these three boundary classes as justified exceptions in the S09 timing-constraint review (without fabricating I/O OFFSET numbers). S09's requirement is no unconstrained *functional clocks or critical data paths*, not literally zero entries in TRCE's unconstrained display. On the evidence above, timing coverage and closure for the as-built 50 MHz lab image are ready for engineer Gate review, subject to confirming this documented asynchronous-boundary interpretation. This does not certify MTBF, physical UART reliability or board acceptance under S11.
