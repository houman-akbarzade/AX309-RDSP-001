# AX309 Radar Lab

اجرا از ریشه مخزن:

```bash
python3 -m desktop_app
```

میانبر **AX309 Radar Lab** در منوی برنامه‌ها و فایل **AX309-Radar.desktop** روی دسکتاپ ایجاد شده است. وابستگی‌های فعلی: Python، NumPy، PySide6 و pyserial. برنامه روی میزبان واقعی اجرا و پنجره آن مشاهده شد.

- **Hardware:** پروگرام موقت طرح UART/IQ موجود، نشست R1 و انتقال/بازخوانی بایت‌به‌بایت IQ سناریوی انتخابی. در نسخه فعلی DSP سخت‌افزاری اجرا نمی‌شود؛ برنامه این محدودیت را نمایش می‌دهد. هر اجرا FPGA را دوباره در SRAM پروگرام می‌کند و نشست قبلی را پاک می‌کند. Flash نوشته نمی‌شود.
- **Reference:** اجرای مدل عددصحیح C04/C05 با ضرایب و شیفت‌های ثابت C02 و نمایش تمام رکوردها، نقشه برد–داپلر و تطبیق آزمایشی با حقیقت سناریو.
- **Demo:** تصویر مصنوعی ساخته‌شده روی رایانه، بدون ادعای آشکارسازی یا اتصال برد.

هر Run یک CPI شامل 33×128 نمونه مختلط تولید می‌کند. پارامتر path span فقط مدت مسیر نمایشی است و اجرای پیوسته چند CPI محسوب نمی‌شود. مسیرها داده معلوم شبیه‌ساز هستند و از FPGA تخمین زده نشده‌اند. محدودیت سرعت شعاعی بدون ابهام [-7.5,7.5) m/s در رابط کنترل می‌شود؛ سرعت مماسی صرفاً برای نمایش مسیر است.

هشت سناریو موجودند. آزمون مرجع هر هشت مورد اجرا شد؛ تطبیق آزمایشی اهداف برای هفت مورد برقرار بود و مورد اهداف نزدیک FAIL شد. رکوردهای اضافی حذف نمی‌شوند. این نتایج تأیید REQ-RNG-03، Pfa/Pd یا پذیرش نهایی نیستند.

آزمون‌های قابل تکرار:

```bash
python3 -m unittest discover -s tests -p 'test_s05_pc*.py' -v
bash rtl/tb/run_radar_cpi.sh
QT_QPA_PLATFORM=offscreen python3 -m desktop_app --smoke
QT_QPA_PLATFORM=offscreen python3 -m desktop_app.smoke
# روی میزبان متصل به برد؛ پروگرام SRAM و آزمون IQ دو سناریو:
QT_QPA_PLATFORM=offscreen python3 -m desktop_app.smoke --hardware
bash rtl/tools/run_xst_radar_cpi_core.sh
```

مسیر ابزارهای محلی Icarus و openFPGALoader در کد و اسکریپت‌ها مشخص است. برای میزبان دیگر، مسیر Icarus با IVERILOG، VVP و IVERILOG_BASE قابل تنظیم است. هنگام نصب عادی ابزارها، این متغیرها را به مسیرهای میزبان تنظیم کنید.

**مانع فعلی تحویل:** سنتز هسته کامل DSP پس از یک دور بهینه‌سازی، 11507 LUT در مقابل ظرفیت 5720 LUT نشان می‌دهد؛ UART و حافظه IQ در این عدد نیستند. هیچ Bitstream کامل DSP، MAP/PAR یا timing closure برای این هسته ادعا نمی‌شود. ادامه نیازمند بازطراحی مصرف منابع و سپس تکمیل RUN/RESULT/COMMIT/ABORT است.
