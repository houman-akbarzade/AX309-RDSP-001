## C-SIG-01 | Discrete LFM and matched filter
N=128, fs=1e6 Hz, L=16 samples, pulse length T=16us, B=250kHz; midpoint sample t_j=(j+0.5)/fs for j=0..15 and chirp rate mu=B/T. Complex baseband pulse s[j]=exp(i*2*pi*(-B*t_j/2+mu*t_j*t_j/2)). Its continuous instantaneous frequency sweeps -125 to +125kHz; sampled first/last instantaneous frequencies are -117187.5 and +117187.5Hz. Rectangular duration 16 samples and s=0 outside support. Reference chirp unit modulus, deterministic phase at t=0=0.
Input echo for integer delay k and slow pulse m: a*s[n-k]*exp(i*2*pi*fd*m*PRI+i*phi), PRI=1ms, fd=2*v/lambda with positive v approaching. Each echo lies k..k+15; full echo contained iff 0<=k<=112. Physical range per delay sample uses exact c=299792458m/s, deltaR=149.896229m; 150m is rounding only. Grid suite target delays k=20,40,60 represent close approximations to 3,6,9km; exact nominal distances use a fractional-delay separately defined suite, not silently rounded truth.
h[j]=conj(s[15-j]) for j=0..15. Linear convolution z=x*h has output index q=0..142. Delay-aligned MF p[k]=z[k+15], with zeros outside input support. Noiseless isolated full echo has peak index exactly k after delay compensation, and theoretical peak magnitude=16*|a|. Define MF range search k=0..112; edge k=0,112 examined separately. Do not mistake full-echo support for CFAR CUT-valid range. Peak equality cases are explicit errors in clean single-target grid tests, not silently resolved.
Numerical taps and fixed-point bit growth follow S04; measured range sidelobes and two-target separability are S03 responsibilities. 600m nominal c/(2B) resolution is theory, not measured outcome.

## C-DAT-01 | Binary IQ, noise, SCR and reproducibility
IQ wire bytes: pulse-major m=0..32 then range n=0..127; each sample I then Q, little-endian two's-complement int16 each, total 33*128*4=16896B. Candidate signed Q1.15 binary conversion for normalized signal: integer=clip(round_to_nearest_ties_even(x*32768),-32768,32767). Exact non-clipping source normalization to be tracked; any saturated samples reported and clean vectors require zero saturations. Raw byte vector and metadata have separate SHA-256 hashes.
Save fixed PCG64 algorithm/version with NumPy version, 128-bit seed decimal representation and independent CPI/scenario substream seeds; generator source hash, environment lock, sample ordering, exact parameter manifest, quantizer mode, clipping count and raw-vector hash. Bit-identical replay required for pinned environment and frozen vector artifact; not claimed across unrelated library versions.
For isolated target i, average P_echo_i=sum_j|a_i*s[j]|²/16 over active echo only; w~CN(0,sigma²), E|w|²=sigma², real/imag each variance sigma²/2. SNR_i=10log10(P_echo_i/sigma²) measured at ideal complex input before summing noise and before quantization. At 0,10,20dB choose sigma² accordingly; finite record measured SNR and Monte Carlo confidence reported separately without claiming exact realized noise power each CPI.
SCR_i=10log10(P_echo_i/P_clutter_i); P_clutter_i is average |c[m,n]|² on the active echo support n=k_i..k_i+15, m=0..32. For multi-target cases report each mask; the +10/-10dB scenario uses homogeneous clutter power across all defined masks; heterogeneous clutter reports distinct SCRs. No-clutter separate. Define statistical sample tolerance in S03 generator test before execution. Input echoes fractional delay off grid belong to separate explicit suite.

## C-DOP-01 | MTI, FFT, deterministic ties, and test eligibility
MTI first-difference y[m,k]=p[m+1,k]-p[m,k], m=0..31. Signed unshifted DFT uses b=0..15 -> b_s=b, b=16..31 -> b_s=b-32; bin 16 is negative Nyquist. Approaching is positive. Historical accepted nominal speed-bin spacing 0.46875 m/s uses c_ref=3e8 m/s; velocity half-bin limit 0.234375 m/s. Distinguish exact-c reporting from this explicitly fixed nominal Doppler label convention.

NORMATIVE DETERMINISTIC OUTPUT RULE (all input states, not limited to performance-qualified trials): compute 32 power values in final fixed-point representation per range cell; choose bin with highest numerical power. If several bins have exactly equal maximum quantized power, choose the bin having the smallest signed b_s; if needed, smallest unshifted b as secondary tie-break. Return selected bin and deterministic status; on all-zero bins (including MTI-stationary target), emit NO_VALID_PEAK status rather than invent a velocity, while preserving a deterministic default index sentinel in the output schema to be frozen in S05. For nonzero exact ties, report PEAK_TIE flag. FPGA vs bit-true reference must agree exactly for normal, tie, zero and overflow cases. A tie does NOT permit nondeterministic RTL output.

SEPARATE HALF-BIN ELIGIBILITY (not a general failure waiver): an isolated dominant test target is eligible for half-bin velocity-error assessment iff its true unambiguous velocity is within the selected folded interval, input target is not stationary/DC-nulled, output power peak is strictly >0 and the computed maximum has exactly one bin (no exact ties), and the peak power exceeds both adjacent circular bins; label the result ELIGIBLE. Without these conditions label NOT_ELIGIBLE with reason and retain it in test denominators and separate summary. Each planned on-bin and off-bin test group must report attempted, eligible and ineligible counts, and no ineligible test may be silently dropped. In the qualifying tests, nearest-bin error <=0.234375 m/s; peak border/bin-tie tests must pass deterministic bit-true output and status rules but are not adjudicated by the half-bin bound. S02 has no approved minimum eligibility fraction across stochastic tests; it cannot claim success for a test set containing no eligible trials. Any new requirement for minimum fraction needs engineer-approved protocol revision before testing.

LEAKAGE AND TRUTH ASSOCIATION: rectangular 32-bin FFT baseline. Leakage power ratio in dB: 10log10(sum outside peak/max(peak,eps)) for a single target, with eps pre-frozen in the numerical reference. Truth matching is host-side performance scoring, distinct from FPGA grouping. Form feasible matches using assignment gate R_GATE=2*range_sample_spacing and V_GATE=1*velocity_bin_spacing (in consistent nominal c=3e8 reporting convention). Build cost C=(dR/R_GATE)^2+(dv/V_GATE)^2 for pairs within both gates. Optimize (1) cardinality maximum (2) total cost minimum (3) lexicographically smallest matching pairs (truth ID, detection ID). No truth or detection is assigned twice. Assignment gate determines which detections count as candidate matches ONLY; it must never replace or weaken the separate estimator acceptance threshold. Full details are independent structured fields in v0.7 matrix.

## C-CFAR-01 | Exclusive normative CA-CFAR geometry and detector
The only operative Pfa statistical protocol is C-CFAR-02. This section does not prescribe any second statistical algorithm.
Input is a linear nonnegative 128x32 range-Doppler power map after MTI and Doppler FFT. Each 7x7 window excludes its central 3x3 guard+CUT square; 40 training cells remain. For unpadded and nonwrapped edge handling and full 16-sample received echoes, CUT range k=3..109 (107 rows), unshifted Doppler b=3..28 (26 columns): 2782 CUTs per CPI. Other CUTs are INVALID and excluded from Pfa denominator. Training estimate Z=sum(40 training powers)/40. Detect iff P_CUT>alpha*Z; equality => no detection.
The IID-exponential alpha0=40*(0.001**(-1/40)-1) is only an initial analytic design value, not guaranteed Pfa in correlated RD data. A final alpha must be fixed using a separately seeded calibration dataset and deterministic predeclared optimization algorithm in S03, before and independently of the main validation set. S04 specifies fixed-point scaling. FPGA implementation may reuse memory and arithmetic, and no statistic-interval estimation is a required on-FPGA function.

## C-UART-01 | FPGA UART transport and debug readback
Onboard CP2102GM, initial UART 8N1 at 115200 baud (must be confirmed on board). Byte frame: four-byte SOF A5 5A C3 3C; uint8 version=1; uint8 type; uint8 flags; little-endian uint32 sequence; little-endian uint16 payload length 0..512; payload; little-endian uint32 CRC-32. CRC over bytes from version through end of payload, excluding SOF and CRC itself. CRC-32/ISO-HDLC reflected polynomial 0xEDB88320, initial register FFFFFFFF, final XOR FFFFFFFF; standard check ASCII 123456789 -> CBF43926. Maximum frame size 529 bytes. Parser accepts frame only after version/type/length/expected sequence and CRC validation, and resynchronizes by byte scanning after malformed length, timeout or CRC error. SOF appearing in payload alone is not sufficient for acceptance.
Define packet TYPE command, IQ_UPLOAD, STAGE_REQUEST, STAGE_DATA, RESULT, ACK, NACK, STATUS; distinct values fixed by ICD no later than S05. IQ_UPLOAD carries uint32 CPI ID and uint32 byte offset preceding chunk data. Reassembly must cover all 16896 bytes with no missing or overlapping byte ranges; full CPI uploaded and acknowledged before run command. A readback or full-CPI digest must be used to verify host bytes; SHA-256 on FPGA is not required if equivalent byte-accurate host readback exists.
Stop-and-wait ARQ: monotonic sequence per link direction; ACK exact sequence, duplicate acknowledged idempotently without reapplying payload, out-of-order NACK with expected sequence, up to 3 retransmissions after initial send, timeout nominal 2s per frame at configured 115200 baud, abort CPI with explicit status on exhaustion; no invisible completion. Fault test matrix corruption, truncation, CRC changes, duplicate, missing, reorder, timeout and recovery. For all *injected test faults*, require either appropriate retry/recovery or unambiguous failure, never a falsely successful CPI. CRC detects many but not mathematically all error patterns.
Full intermediate output for each of seven FPGA functions accessible by stage request and segmented STAGE_DATA with CPI/offset/type/schema; deterministic reruns allowed without simultaneous buffer retention. Binary readback compared bytewise with corresponding bit-true reference under identical initial conditions. Timing metrics distinguish link transfer time and FPGA-only cycle measurement.

## Replacement interval: pre-calibrated skewness-corrected Studentized CPI mean
For each independent CPI i=1..G=4096 define F_i number of false alarms over 2782 valid CUT and X_i=F_i/2782. Define
xbar=(1/G)*sum X_i;
m_2=(1/G)*sum (X_i-xbar)^2;
m_3=(1/G)*sum (X_i-xbar)^3;
s=sqrt( (1/(G-1))*sum (X_i-xbar)^2 );
gamma_hat=m_3/m_2^(3/2).
Let z=Phi^{-1}(.95)=1.6448536269514722, t=t^{-1}_{4095}(.95).
The *exclusive candidate* one-sided upper interval is:

U_cal = clamp_[0,1] { xbar + [t + Delta_star]*s/sqrt(G) +
                     gamma_hat*s*(2*z^2+1)/(6*G) }.

For Delta_star=0 this is the first-order Studentized Edgeworth/Cornish-Fisher upper approximation. Its skewness sign and coefficient follow from F_T(x)=Phi(x)+gamma*(2x^2+1)phi(x)/(6sqrt G)+O(G^{-1}) for T=sqrt G*(xbar-p)/s. Inverting at 5% gives q_.05=-z-gamma*(2z^2+1)/(6sqrt G)+O(G^-1), and U=xbar-q_.05*s/sqrt G; thus **positive skewness demands a positive upper-bound correction**. gamma_hat is the unadjusted third central standardized moment with m_2 and m_3 denominators G; the Studentizing s uses denominator G-1. Using t instead of z for the base quantile changes higher-order terms, not the first-order skewness coefficient.

This Edgeworth formula is NOT a finite-sample guarantee and does NOT equal the symmetric Johnson interval, which has a different skew correction. The extra nonnegative Delta_star is a PREDECLARED independent calibration of the 95th upper quantile of a corrected adverse studentized score, not a fitted response to past failed qualification data.

### Prospective critical-value calibration algorithm (not executed)
Before generating any calibration outcomes, freeze source code hashes, NumPy/SciPy versions, SeedSequence stream partition, all model parameters and numeric algorithm. Use 15 fixed conditions (rho 0, .001, .01, .03, .05 crossed with p=.0005,.001,.0015) and exactly N_cal=5000 **new independent** outer simulated datasets per condition, each containing G=4096 independent CPI counts. This is a separate CI-CALIBRATION corpus, not physical CFAR alpha calibration and NOT qualification or main validation.

For each *VALID* outer dataset at generating p, compute the adverse score:
A=(p-xbar)/(s/sqrt G) - gamma_hat*(2*z^2+1)/(6*sqrt G).
Validity checks are preexisting: >=100 CPI with alarms, >=100 alarms total, and positive finite variance; invalid => INCONCLUSIVE and separately counted. If fewer than 4750 of 5000 datasets per condition are valid, STOP/BLOCK calibration (do not remove or replace difficult conditions). Otherwise sort the m valid A values.

Familywise quantile uncertainty: Bonferroni delta=.05/15 per condition. For each condition define r(m)=1+ BinomialQuantile(1-.05/15; m, .95), 1-based indexing. The r(m)-th sorted adverse score gives a nonparametric one-sided familywise-protected upper estimate of its population 95th percentile. With m=5000 valid data, r=4792, and P[BIN(5000,.95)<=4791]=.99709978 >=1-.05/15. For each condition compute Q_i=A_(r_i). Freeze

Delta_star = max(0, max_{i=1..15} Q_i - t).

If this computation fails, any adverse score/Delta_star is nonfinite, or any model fails calibration validity limits, calibration is BLOCKED, not re-tuned. **This is the engineer-approved deterministic algorithm. Delta_star has NOT YET been computed.** Its population quantile protection is conditional on independent, correctly simulated CPI-count surrogate models; it DOES NOT prove operational real-chain coverage.

## Computation and decision logic
CI calibration: 15*5000*4096=307,200,000 CPI count draws. New formal CI qualification: 15*3000*4096=184,320,000 further count draws. Together 491,520,000 draw operations, O(G) working space via chunking. No 150-million nested bootstrap resamplings. This is about 1250x fewer generated count samples than the 614.4-billion index draws of rejected nested-bootstrap plan (NOT a measured CPU runtime ratio). G=4096 stays fixed for the main validation, saving 4x serial/CPI transfer time versus a 16384-CPI option.

This proposal preserves rejection of all previously failed qualifications, all original alpha/Pfa thresholds and all 15 conditions; it adds a globally calibrated *conservative* critical term from completely independent predeclared datasets. It may reduce power to accept a genuinely compliant p≈.001 if Delta_star proves large. Power must be **reported, never optimized after qualification**; if prospective calibration yields no viable bound or the method fails qualification, stop and return for a new explicit engineer decision. No automatic guarantee of method success is asserted.
