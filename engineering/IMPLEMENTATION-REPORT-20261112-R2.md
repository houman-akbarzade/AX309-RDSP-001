# AX309-RDSP-001: گزارش اجرای R2

وضعیت تحویل: **ناقص؛ ارتباط و حافظه IQ روی برد تأیید شد، DSP سخت‌افزاری BLOCKED است.**

| مورد | نتیجه واقعی |
|---|---|
| مجوز UART | اصلاح و دسترسی موفق به /dev/ttyUSB1 |
| JTAG | شناسایی XC6SLX9 با IDCODE=0x04001093 توسط openFPGALoader؛ iMPACT قبلی ناموفق بود |
| پروگرام | بارگذاری SRAM طرح UART/IQ؛ DONE=1؛ بدون نوشتن Flash |
| نشست و IQ | PASS؛ 16896 بایت، 35 بسته ارسال و 35 بازخوانی، تطبیق کامل |
| IQ سناریوها | تک‌هدف و دوهدف با مسیر Worker برنامه روی برد PASS؛ این آزمون DSP نیست |
| DSP متصل در RTL | MF16 → MTI2 → FFT32 → Power → CFAR → Grouping پیاده شد |
| تطبیق دقیق RTL | سه CPI صفر/تک‌هدف/چندهدف؛ هر خروجی MF، MTI، FFT، Power و تمام رکوردهای نهایی با C04/C05 یکسان؛ backpressure آزموده شد |
| ابزار شبیه‌سازی | Full-chain با Icarus 12.0؛ ISim برای این TB دچار خطای داخلی شد. FFT بهینه‌شده جداگانه در ISim نیز PASS شد |
| بهینه‌سازی Power | شش ضرب جزئی با یک ضرب‌کننده مشترک؛ دقت U46.30 حفظ شد |
| بهینه‌سازی FFT | گردکردن دقیق ویژه شیفت‌های ثابت 15/16؛ 8086 مورد تطبیق با تابع عمومی PASS |
| سنتز هسته DSP | از 12309 به 11507 LUT کاهش یافت؛ ظرفیت 5720؛ FIT=FAIL |
| سایر منابع هسته | 3754 FF، 18 BRAM، 13 DSP48A1؛ شامل UART/حافظه ورودی نیست |
| طرح کامل و timing | سنتز ترکیب UART+DSP و MAP/PAR/TRCE آن اجرا نشده؛ هیچ جمع برآوردی به‌عنوان fit ارائه نشده |
| برنامه دسکتاپ | PySide6، هشت سناریو، سه حالت، جدول حقیقت/خروجی، مسیر مرجع و نقشه برد–داپلر؛ smoke و اجرای بومی موفق |
| کیفیت سناریو مرجع | هشت اجرا؛ هفت تطبیق آزمایشی اهداف PASS، اهداف نزدیک FAIL؛ رکوردهای اضافی در خروجی حفظ شدند |
| رگرسیون ارتباطی | 57 PASS |

کنترل‌گر جدید برای حذف حافظه کامل MF، داده خام را نگه می‌دارد و MF را برای زوج پالس‌های موردنیاز هر برد دوباره محاسبه می‌کند. محاسبات عددی و قراردادها تغییر نکرده‌اند. این انتخاب در سه CPI با تطبیق خروجی تمام مراحل آزموده شد؛ ادعای پذیرش آماری نیست.

مانع فعلی صرفاً نبود کابل یا مجوز نیست. خود هسته DSP بیش از دو برابر LUT تراشه مصرف می‌کند. لازم است حافظه چنددرگاهی و کنترل FFT و منطق Grouping/کنترل بازطراحی و اشتراک منابع بیشتر شود. پس از fit، اتصال UART RUN/RESULT، تصمیم نهایی CPI و بازیابی خطا، ساخت طرح کامل، timing و آزمون DSP واقعی روی برد هنوز لازم است. این هسته روی برد پروگرام نشده است.

پیشرفت محافظه‌کارانه مطابق مدل موجود: S05 از 44% به 45%، شاخص مرحله‌ای کل از 37% به 37.0833%، فقط بابت یک امتیاز آزمون واقعی برد. کد جدید هسته و برنامه پیش از حل fit و معیارهای خروج بسته‌ها امتیاز اضافی نگرفتند. این درصد، سهم تحویل کارکرد نهایی نیست. پذیرش مهندسی مستقل و بدون افزایش باقی ماند.

REQ-RNG-03 همچنان FAIL، پذیرش نهایی REQ-LIST-01 باز، ریسک آماری Fixed-Point باز و هفت قرارداد readback میانی باز هستند. تصمیم مهندس درباره بسته‌شدن S04 با موارد باز حفظ شد. آزمون‌های آماری S04 و 16 CPI قبلی تکرار نشدند.
