راهنمای AX309 Radar Lab

نمای چپ: مسیر معلوم اهداف
مسیرها از سناریوی ورودی رسم می‌شوند. دایره، موقعیت در مرکز بازه نمایشی است. این مسیرها رهگیری یا تخمین زاویه توسط FPGA نیستند. پردازش فعلی فقط برد و سرعت شعاعی را برآورد می‌کند.

نمای راست: نتیجه پردازش منبع انتخاب‌شده
در حالت Hardware، نقشه Power و رکوردهای کلاستر از خود FPGA دریافت می‌شوند. محور افقی سرعت شعاعی و محور عمودی برد است. حلقه زرد قله کلاستر، ضربدر سبز هدف معلوم و نقطه قرمز سلول CFAR است.

کنترل‌های ورودی

  • Scenario: تک‌هدف، دوهدف، مسیرهای متقاطع، چندهدف، هدف ضعیف کنار قوی، کلاتر، اهداف نزدیک و SNR پایین.
  • Result source: Hardware اجرای واقعی برد؛ Float reference مرجع Float64؛ Legacy fixed reference مدل عددصحیح FFT قبلی؛ Demo فقط تصویر مصنوعی.
  • UART: نام پایدار CP2102؛ ارتباط 115200 baud و 8N1.
  • Range offset: جابه‌جایی برد همه اهداف بر حسب سلول 149.896 متری.
  • Velocity offset: تغییر سرعت شعاعی همه اهداف؛ شبکه داپلر 0.46875 متر بر ثانیه است. سرعت خارج بازه [-7.5,7.5) رد می‌شود.
  • Amplitude multiplier: ضریب دامنه اهداف؛ توان با مربع دامنه تغییر می‌کند.
  • Complex noise RMS: RMS نویز مختلط ورودی، بر حسب دامنه نرمال‌شده؛ 0 برای بدون نویز.
  • Seed: بذر نویز برای تکرارپذیری. انتخاب Low SNR مقدار پیش‌فرض نویز را 0.06 می‌کند.
  • Path span: طول زمانی مسیر نمایشی؛ نرخ واقعی یا مدت انتقال داده نیست. هر Run تنها یک CPI از 33×128 نمونه مختلط است.

اتصال و اجرا

Refresh ports درگاه‌های سریال را فهرست می‌کند. Program FPGA طرح کامل را فقط در SRAM پروگرام می‌کند و نشست قبلی را پاک می‌کند؛ Flash تغییر نمی‌کند. پس از یک بار پروگرام، چند Run متوالی بدون پروگرام مجدد ممکن است. Hardware Run به ترتیب IQ را می‌فرستد، بازخوانی را بایت‌به‌بایت کنترل می‌کند، RUN می‌دهد، همه کلاسترها را می‌گیرد، COMMIT را بررسی و ثبت می‌کند، نقشه واقعی Power را می‌خواند و CPI را RELEASE می‌کند.

اگر ارتباط قطع شد، نتیجه ناقص معتبر نمایش داده نمی‌شود. پیش از پروگرام مجدد، گزارش خطا و وضعیت CPI قبلی نگه داشته می‌شود. بازیابی خودکار نشست نیمه‌تمام هنوز فراهم نیست.

کنترل‌های نمایش

  • Range–Doppler: نقشه دوبعدی توان با جابه‌جایی FFT به سرعت‌های منفی/مثبت.
  • Range profile: بیشینه توان روی داپلر برای هر سلول برد.
  • Doppler slice: توان داپلر در سلول برد انتخاب‌شده؛ با انتخاب یک رکورد جدول نیز تغییر می‌کند.
  • Power dB / Linear: توان نرمال‌شده؛ dB برابر 10log10(P)، بدون کالیبراسیون به dBm.
  • Dynamic range: دامنه رنگ نسبت به قوی‌ترین سلول، بر حسب dB؛ فقط نمایش را تغییر می‌دهد.
  • Clusters / Truth: روشن و خاموش کردن قله‌های واقعی و موقعیت معلوم اهداف.
  • CFAR cells: در Hardware از نقشه Power دریافت‌شده، با همان محاسبه عددصحیح روی PC بازسازی می‌شود؛ خود رکوردهای کلاستر از FPGA هستند.
  • Valid CUT region: محدوده CFAR با برد 3..109 و داپلر 3..28؛ بیرون آن آشکارسازی انجام نمی‌شود.
  • Compare Float: مقایسه توان و مشخصات قله/اندازه کلاسترها با مرجع مستقل Float64 روی منبع پیش از کوانتیزه‌کردن IQ؛ مقایسه کامل عضویت خوشه از رکوردهای نهایی ممکن نیست.
  • Save results: ذخیره JSON و CSV همه رکوردها همراه منبع نتیجه؛ هیچ کلاستر اضافی حذف نمی‌شود.

زمان انتقال IQ، انتظار نتیجه و کل اجرا جدا نمایش داده می‌شوند. زمان انتظار نتیجه شامل انتقال UART رکوردها است و اندازه‌گیری خالص تأخیر DSP نیست. تطبیق اهداف یک معیار توسعه است؛ تأیید آماری Pd/Pfa و حل محدودیت اهداف نزدیک محسوب نمی‌شود.
